# Security Policy

Only the latest deployment of `main` at [kevinpierik.dev](https://www.kevinpierik.dev) is supported.

Please do not report vulnerabilities in public issues. Use [GitHub private vulnerability reporting](https://github.com/kevin-pierik/kevinpierik-dev/security/advisories/new) or email kevinpierik@icloud.com. You will get a reply within a week.
